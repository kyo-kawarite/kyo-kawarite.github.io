プライバシーポリシー

KAWARITE ／ 最終更新日: 2026年9月22日

KAWARITE（以下「本アプリ」）は、フリーランスのクリエイター向けのデスクトップアプリです。本ポリシーは、本アプリが 取り扱う情報と、その使い方・保管・削除について定めます。本アプリは現在クローズドベータであり、開発者が個人的に 知っている限られた利用者にのみ提供しています。

1. 取り扱う情報

本アプリは、利用者が接続を許可したサービスから、次の情報を取得します。接続していないサービスの情報は取得しません。

サービス 取得する情報 目的
Gmail 利用者が KAWARITE ラベルを付けた相手からのメールの、差出人・件名・本文・日時。 利用者が承認した返信の送信。 受信箱への表示、返信案の作成、案件との紐づけ
Discord 利用者のアカウントが参加しているチャンネル・DMのメッセージ 同上
freee 事業所・取引先の情報、本アプリから作成した請求書 請求書の作成
利用者が入力・取り込むもの 案件、打ち合わせの録音とその書き起こし、TODO、契約書のファイル 本アプリの各機能の提供

本アプリは、メールの既読・未読の状態を変更しません。また、利用者がラベルを付けていない相手のメールは取得しません。

2. Googleユーザーデータの取り扱い（Limited Use）

本アプリがGoogle APIから受け取った情報の使用および転送は、 Google API Services User Data Policy（Limited Use requirements を含む）に準拠します。

具体的には、Gmailから取得した情報について、次のことを行いません。

  • 広告の表示・配信のために使用すること
  • 本アプリの機能提供以外の目的で使用すること
  • 第三者へ販売・提供すること（下記「4. 第三者への提供」の場合を除く）
  • 人が内容を読むこと（法令に基づく場合、利用者の明示的な許可を得た場合、セキュリティ上の調査や障害対応で必要な場合を除く）

本アプリが求めるGmailの権限は、gmail.readonly（読み取り）と gmail.send（送信）だけです。 メールの削除・ラベルの変更・設定の変更はできません。

3. 保管と安全対策

  • 取得した情報は、Supabase（クラウドのデータベース）に保管します。通信はすべて暗号化されます（TLS）。
  • 各サービスへの接続の鍵（アクセストークン等）と、取り込んだ契約書の原本・その要約は、暗号化して保管します （AES-256-GCM）。暗号鍵はアプリには含まれず、サーバー側で管理します。
  • データベースは、利用者ごとにアクセスを制限しています（行レベルセキュリティ）。ほかの利用者のデータは参照できません。
  • メッセージの本文・議事録の書き起こしは、現時点では暗号化せずに保管しています（検索のため）。上記のアクセス制限で保護しています。

4. 第三者への提供

本アプリは、取得した情報を販売しません。機能の提供に必要な範囲で、次のサービスにのみ送信します。

送信先 送るもの 目的
Anthropic（Claude） 利用者が指示した処理に必要な範囲の文章（メッセージ、議事録、契約書の内容など） 返信案の作成、要約、質問への回答
OpenAI 打ち合わせの録音 文字起こし
freee 請求書の内容（取引先・件名・金額など） 請求書の作成
Supabase 上記「1. 取り扱う情報」のデータ 保管

これらの送信先では、送った内容がAIの学習に使われない条件で利用します。契約書については、取り込むときに 「AIで要約する」か「保管するだけ（AIに渡さない）」を利用者が毎回選べます。

5. 保存期間と削除

  • 取得した情報は、利用者が削除するまで保管します。
  • AIとの会話（CHAT）は、最後の更新から1週間で自動的に削除されます（利用者が固定したものを除く）。
  • 各サービスの接続は、アプリの「接続設定」からいつでも解除できます。解除すると、その接続の鍵は削除されます。
  • 保管している情報の削除を希望する場合は、下記の連絡先までご連絡ください。速やかに削除します。
  • Googleアカウント側からも、サードパーティ製アプリとの連携でいつでもアクセスを取り消せます。

6. 未成年の利用

本アプリは、業務で利用する成人を対象としており、13歳未満の方の利用を想定していません。

7. 本ポリシーの変更

内容を変更する場合は、このページを更新し、最終更新日を改めます。
